# 🎨 How to Edit Your Login Page Branding

## What You Can Edit

All branding elements shown on the **Login Page**:

1. **🖼️ Logo Image** - The circular logo/graphic at the top
2. **📝 System Name** - "Asset Management System" (or your custom name)
3. **🏢 Organization Name** - "Vanuatu Bureau Of Statistics" (or your organization)

**All three elements are editable in one place!**

---

## Quick Access

You can edit your organization's logo and branding in **3 easy ways**:

### 1. Dashboard Quick Link (Fastest!) ⚡
- Login as **Admin**
- On the dashboard, click the **"Logo & Branding"** button in the top-right corner
- Or click the colorful **"Edit Logo & Branding"** card below the metrics

### 2. Navigation Menu
- Go to **Setup/Configuration** → **System Settings**

### 3. Direct URL
- Navigate to: `http://your-domain/settings/system`

---

## What You Can Customize

### 🖼️ Logo Image
- Upload your organization's logo or emblem
- Appears at the top of the login page
- Also shown in navigation bar and headers

### 📝 System Name (Site Subtitle)
- The main heading on the login page
- Currently: "Asset Management System"
- Change to any name you prefer
- Example: "Inventory System", "Asset Tracker", etc.

### 🏢 Organization Name (Site Title)
- Your organization's official name
- Currently: "Vanuatu Bureau Of Statistics"  
- Displays below the system name on login page
- Shows in page titles and headers

---

## Step-by-Step Instructions

### Step 1: Access System Settings
1. Login with **Admin** credentials
2. Click **"Logo & Branding"** button on dashboard
   - OR go to Setup/Configuration → System Settings

### Step 2: Preview Current Settings
- You'll see your current logo displayed at the top
- Current site title and subtitle are shown

### Step 3: Update Information

**To change the Organization Name (bottom text on login):**
1. Edit the **"Organization Name"** field
2. Example: Change from "Vanuatu Bureau Of Statistics" to "Your Organization"

**To change the System Name (main heading on login):**
1. Edit the **"System Name"** field  
2. Example: Change from "Asset Management System" to "Inventory Management"

**To change the Logo (image on login):**
1. Click **"Choose File"** under "Upload New Logo"
2. Select your logo image file (PNG, JPG, GIF, or SVG)
3. Preview will update automatically

### Step 4: Preview Login Page Appearance
- The preview section shows exactly how it will look on the login page
- Check:
  - ✅ Logo displays clearly
  - ✅ System name is correct
  - ✅ Organization name is correct

### Step 5: Save Settings
- Click the **"Save Settings"** button
- You'll see a success message
- Changes apply immediately across the entire system

## Tips for Best Results

### Logo Requirements
✅ **DO:**
- Use high-quality images (minimum 200x200px)
- Use transparent background (PNG format)
- Keep design simple and recognizable
- Test logo at different sizes
- Use your official brand colors

❌ **DON'T:**
- Use low-resolution images
- Use complex designs with tiny details
- Upload extremely large files (keep under 500KB)
- Use white logo on white background

### After Upload
- Clear browser cache (Ctrl + F5) to see changes immediately
- Logo appears on:
  - Login page
  - Sidebar navigation
  - Page headers
  - Dashboard
  - All printed reports

### File Size Guidelines
- **Ideal:** 50-200 KB
- **Maximum:** 2 MB
- **Recommended Dimensions:** 200x200px to 500x500px

---

## Troubleshooting

### Logo not updating?
1. **Clear browser cache:** Press Ctrl + Shift + Delete
2. **Hard refresh:** Press Ctrl + F5
3. **Check file format:** Ensure it's PNG, JPG, GIF, or SVG
4. **Verify file size:** Should be under 2MB

### Upload fails?
- Check file format is supported
- Ensure file size is not too large
- Verify you're logged in as Admin
- Check browser console for errors

### Logo appears distorted?
- Use square images (same width and height)
- Use PNG with transparent background
- Try uploading a larger resolution
