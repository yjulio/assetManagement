## 🎯 How to Upload a New Logo

### Method 1: Drag & Drop (Easiest!)
1. Go to **Settings → System Settings**
2. Drag your logo image file to the upload area
3. See instant preview
4. Click "Save Settings"

### Method 2: "Change Logo" Button
1. Go to **Settings → System Settings**
2. Click **"Change Logo"** button on current logo
3. Select file from browser
4. See instant preview
5. Click "Save Settings"

### Method 3: Browse Files
1. Go to **Settings → System Settings**
2. Scroll to upload area
3. Click **"Browse Files"** button
4. Select your logo
5. Preview updates automatically
6. Click "Save Settings"

## 📋 Upload Requirements

✅ **Supported Formats:**
- PNG (recommended - supports transparency)
- JPG/JPEG
- GIF
- SVG

✅ **Size Requirements:**
- Minimum: 200x200 pixels
- Recommended: 400x400 pixels or larger
- Maximum file size: 5MB
- Square images work best

✅ **Best Practices:**
- Use transparent background (PNG)
- High resolution for clarity
- Simple, recognizable design
- Test at different sizes

## 💡 Tips & Tricks

### For Best Results:

4. **Simple design** that works at small sizes

## 🔧 Troubleshooting

### Logo not uploading?
- Check file is under 5MB
- Verify format is PNG, JPG, GIF, or SVG
- Ensure you have Admin permissions
- Try a different browser

### Preview not updating?
- Check file uploaded successfully
- Refresh preview section
- Try uploading again
- Clear browser cache (Ctrl+F5)

### Changes not saving?
- Click "Save Settings" button
- Wait for success message
- Refresh page to confirm
- Check server logs if issues persist
